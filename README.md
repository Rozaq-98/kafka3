**Pengertian**

**Procedure**	Kumpulan instruksi/perintah yang dieksekusi untuk satu tugas tertentu	Menjalankan logika seperti insert, update, hitung, dll	Stored Procedure di SQL untuk memasukkan data

**Consumer**	Komponen yang membaca & memproses data dari producer	Mengambil data dari topic dan memprosesnya	Kafka consumer yang membaca event transaksi

**Topic**	Channel/tempat pesan/event dikirim & disimpan	Menjadi jalur komunikasi antara producer dan consumer	Topic transaksi di Kafka
